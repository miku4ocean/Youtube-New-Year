說明

本專案為純靜態前端工具（HTML／CSS／原生 JavaScript），無 build 步驟、無套件依賴、無伺服器端程式碼。 下圖依實際讀取的 index.html、app.js、styles.css、HANDOFF.md 產出， 依專案真實情況將層次縮為五層（無 API 層、無基礎設施層、無 Worker 流水線——因為本工具沒有這些）， 並將全案最關鍵的設計決定（20 支直播網址為寫死於程式碼的年度人工維護資料）做成 accent 色視覺焦點。

Keystone

videoUrls 陣列是全案唯一的「資料」——而它是寫死在程式碼裡的年度資產。 這個專案沒有資料庫、沒有後台可以編輯直播清單；每年跨年前，接手者必須直接編輯 app.js 開頭的 20 支網址（HANDOFF.md 明列為「接手者下一步 #1」）。這個決定讓專案維持零依賴、零後端、 可直接丟給 GitHub Pages 部署，但代價是「年度維護」完全仰賴人工記得更新。
