# 🎆 2025 新年跨年直播合集

一個可以同時觀看多個台灣跨年直播的網頁應用。

## 功能特色

- 📺 **20 個直播頻道**：同時顯示 20 個指定的 YouTube 跨年直播
- 📱 **響應式設計 (RWD)**：
  - 桌機版：每列 4 個影片
  - 平板版：每列 3 個影片
  - 手機版：每列 2 個影片
  - 極小螢幕：每列 1 個影片
- 🔍 **點擊放大**：可點擊任一影片放大觀看
- 🔇 **全部靜音/取消靜音**：一鍵控制所有影片音量
- 📺 **全螢幕模式**：支援全螢幕觀看
- ⏰ **跨年倒數計時**：顯示距離新年的倒數時間
- 🎆 **煙火特效**：新年時刻觸發煙火動畫

## 鍵盤快捷鍵

- `M` - 切換全部靜音
- `F` - 切換全螢幕模式
- `ESC` - 關閉放大的影片

## 直播頻道

本專案包含 20 個預設的跨年直播頻道，可在可滾動的頁面中同時觀看。

## 技術

- 純 HTML / CSS / JavaScript
- 無需額外依賴套件
- 可直接透過 GitHub Pages 部署

## 部署

將專案推送到 GitHub 後，開啟 GitHub Pages 即可使用。
